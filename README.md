# 여행 통역 (웹앱 시제품)

휴대폰 브라우저에서 바로 쓰는 한국어 ↔ 영어 통역 앱입니다. 앱스토어 설치 없이 주소만 열면 되고, 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 사용법
1. **통역 시작**을 누르고 한국어로 말합니다.
2. 영어로 번역되어 화면에 크게 나오고 소리로 읽어 줍니다.
3. 그다음엔 자동으로 **영어 듣기**로 바뀝니다. 상대방이 영어로 말하면 한국어로 번역해 읽어 줍니다.
4. 차례가 꼬이면 아래의 `🇰🇷 한국어로 말하기` / `🇨🇦 Speak English` 버튼으로 직접 바꿀 수 있어요.
5. 다시 누르면 멈춥니다. ⚙︎ 설정에서 글자 크기, 읽기 속도, 자동 차례 바꾸기를 조절합니다.

## 기술 선택과 이유
| 기능 | 사용한 것 | 비용 / 키 | 이유 |
|---|---|---|---|
| 음성인식 | 브라우저 내장 Web Speech API (아이폰 Safari, 안드로이드 Chrome) | 무료, 키 없음 | 휴대폰 OS의 음성인식(애플/구글)을 그대로 써서 정확도가 좋음 |
| 언어 판별 | "번갈아 듣기" + 글자 종류 판별(한글이면 한국어, 알파벳이면 영어) | 무료 | 브라우저 음성인식은 한 번에 한 언어만 들을 수 있어서, 대화 차례를 자동으로 넘기고 결과 글자로 한 번 더 확인 |
| 번역 | Google 번역 무료 엔드포인트 → 실패 시 MyMemory | 무료, 키 없음 | 시제품용. 공식 서비스가 아니라 언제든 막힐 수 있음 |
| 음성출력 | 브라우저 내장 speechSynthesis | 무료 | 휴대폰에 깔린 한국어/영어 음성 사용 |

### 실제 여행 전에 바꾸면 좋은 것
- **번역**: Google Cloud Translation 공식 API(월 50만 자 무료)나 DeepL API Free(월 50만 자 무료)로 교체 권장. API 키가 필요하고, 키를 숨기려면 작은 서버(예: Cloudflare Worker)가 하나 필요합니다.
- **진짜 자동 언어 감지**: 차례를 정하지 않고 누가 말하든 알아들으려면 클라우드 음성인식(OpenAI 음성 API, Google Cloud Speech의 다중 언어 인식 등)이 필요하고 유료입니다.
- **인터넷**: 음성인식과 번역 모두 인터넷이 필요합니다. 캐나다 데이터 로밍/eSIM을 꼭 준비하세요. 완전 오프라인이 필요하면 네이티브 앱(온디바이스 번역 모델)이 낫습니다.

## 휴대폰에서 열려면
마이크는 **https 주소**에서만 켜집니다. 이 폴더를 그대로 아래 중 한 곳에 올리면 됩니다.
- GitHub Pages (저장소에 올리면 `https://아이디.github.io/...` 주소가 생김)
- Netlify Drop (https://app.netlify.com/drop 에 `interpreter-app.zip`을 풀어 폴더째 끌어다 놓기)

## 파일
- `index.html`, `style.css` — 화면
- `app.js` — 음성인식 → 번역 → 읽어주기, 차례 바꾸기
- `translate.js` — 번역 제공자 (여기만 바꾸면 공식 API로 교체 가능)
- `manifest.json`, `sw.js`, `icon*` — 홈 화면 앱(PWA) 설정
