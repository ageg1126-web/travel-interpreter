# 여행 도우미 (웹앱 시제품)

휴대폰 브라우저에서 바로 쓰는 한국어 ↔ 영어 통역 앱입니다. 앱스토어 설치 없이 주소만 열면 되고, 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 화면 구성
아래 탭: **통역**, **사진 번역**, **일정**, **여행 도구**(준비 중), **설정**.

## 사진 번역
- 탭을 열면 뒤쪽 카메라가 켜져요. 메뉴판·표지판을 맞추고 셔터를 누르면 사진을 OpenAI(`gpt-4o-mini` 비전)로 보내 한국어 번역과 짧은 설명을 보여 줘요. "앨범에서 고르기"로 찍어 둔 사진도 번역할 수 있어요.
- 메뉴판은 음식마다 가격과 어떤 음식인지 설명이 붙고, 안내문은 무엇을 해야 하는지 알려 줘요.
- 사진은 긴 변 1600px JPEG로 줄여 보내요. 한 장에 1센트 미만이에요. 다른 탭으로 가면 카메라가 꺼져요.

## 일정
- 링켄리브 견적서(캐나다 로키 기차여행 6박 8일, 2027-07-18 ~ 07-25)를 날짜별로 `schedule.json`에 옮겨 두었어요.
- 캐나다 시간과 한국 시간을 함께 보여 주고, 날짜에 맞춰 밴쿠버(태평양) → 재스퍼부터 산악 시간대로 자동으로 바꿔요. 출발 전엔 D-day, 여행 중엔 몇 일째인지 나와요.
- 여행 중에는 오늘 날짜로 바로 이동하고 "오늘" 표시가 붙어요. 장소를 누르면 구글 지도가 열려요.
- ＋ 버튼으로 추가, 일정을 눌러 수정·삭제할 수 있어요. 휴대폰에서 고친 내용은 그 폰에만 저장돼요.
- `schedule.json`을 고쳐서 올리면(버전 숫자 올림) 모든 폰에 새 일정이 들어가요. 폰에서 직접 고친 게 있으면 "새 일정 불러오기" 안내가 떠요.
- 공유 버튼으로 전체 일정을 글로 보내거나 복사할 수 있어요.

## 통역 사용법
1. 통역 탭에서 가운데 🎤 버튼을 한 번 누르면 계속 듣기 시작해요.
2. 누가 어떤 언어로 말하든 순서 상관없이, 한국어가 들리면 영어로, 영어가 들리면 한국어로 화면에 띄우고 스피커로 읽어 줘요.
3. 휴대폰이 읽는 동안에는 듣기를 잠깐 멈춰서 자기 목소리를 다시 통역하지 않아요.
4. 다시 누르면 멈춰요.

## 두 가지 모드
| 모드 | 조건 | 동작 |
|---|---|---|
| 자동 감지 | 설정에 OpenAI API 키 입력 | 마이크를 계속 열어 두고 말이 끝날 때마다(기본 0.8초 쉼) 잘라서 OpenAI 음성인식(`gpt-4o-mini-transcribe`, 안 되면 `whisper-1`)에 보내요. 결과 글자가 한글이면 한국어, 알파벳이면 영어로 판단해요. 번역은 `gpt-4o-mini`로 하고, 실패하면 무료 번역으로 넘어가요. |
| 기본 모드 | 키 없음 | 브라우저 무료 음성인식. 한 번에 한 언어만 들을 수 있어서 한국어와 영어를 번갈아 들어요. |

### 비용과 키
- OpenAI 음성인식은 1분에 약 0.3센트(gpt-4o-mini-transcribe 기준)라 여행 내내 써도 몇 달러 수준이에요. 번역 비용은 그보다 훨씬 적어요.
- 키는 그 휴대폰 브라우저에만 저장돼요. OpenAI 대시보드에서 **월 지출 한도**를 꼭 걸어 두세요.
- 키는 채팅이나 저장소에 절대 올리지 마세요.

### 알아두실 점
- 음성인식과 번역 모두 인터넷이 필요해요. 캐나다 데이터 로밍/eSIM을 준비하세요.
- 아이폰은 마이크가 켜져 있을 때 읽어주는 소리가 작게 날 수 있어요. 실제 폰으로 꼭 시험해 보세요.
- 주변이 시끄러우면 말 끝을 늦게 알아챌 수 있어요. 설정의 "말 끝 감지"로 조절할 수 있어요.

## 파일
- `index.html`, `style.css` — 화면과 탭
- `app.js` — 탭, 설정, 통역 흐름(자동 감지 / 기본 모드)
- `audio.js` — 마이크를 계속 듣다가 말 한 마디씩 잘라 주는 부분
- `stt.js` — OpenAI 음성인식
- `schedule.js`, `schedule.json` — 일정 화면과 여행 일정 데이터
- `camera.js` — 사진 번역
- `translate.js` — 번역 (OpenAI → 무료 Google → MyMemory 순)
- `manifest.json`, `sw.js`, `icon*` — 홈 화면 앱(PWA) 설정
