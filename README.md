# 여행 도우미 (웹앱 시제품)

휴대폰 브라우저에서 바로 쓰는 한국어 ↔ 영어 통역 앱입니다. 앱스토어 설치 없이 주소만 열면 되고, 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 화면 구성
왼쪽 위 ☰ 버튼으로 여닫는 사이드바 메뉴: **통역**, **사진 번역**, **일정**, **지도**, **보여 주는 카드**, **여행 도구**, **설정**. 앱은 늘 통역 화면으로 열리고, 휴대폰 뒤로가기는 열린 창 → 그 아래 화면 → 통역 순서로 돌아가요. 통역 화면에서 뒤로가기를 누르면 앱이 닫혀요.

## 디자인 (2026-10 개편)
- Android·Galaxy 최신 디자인(Material 3 Expressive, One UI 8.5)을 바탕으로 했어요. 둥근 큰 카드, 꽃·쿠키 모양 아이콘 받침, 붙어 있는 버튼 묶음을 써요. 지도 위 버튼과 떠 있는 버튼에만 유리 효과(iOS 26 Liquid Glass식)를 써요. 글 내용에는 쓰지 않아요.
- 어떤 화면도 휴대폰 폭보다 넓으면 안 돼요(넓으면 휴대폰이 화면 전체를 넓혀서 가운데가 틀어지고 확대돼 보여요). 원 뒤 빛처럼 밖으로 퍼지는 효과는 꼭 감싸는 칸 안에서 잘라요.
- 색은 "① 빙하 호수"예요. 주 색은 청록 `#00696B`, 포인트는 산호 `#E8603F`이에요. 어두운 화면 색도 따로 있어요.
- 원 애니메이션은 "리퀴드 글래스 구슬"이에요(`orb.js`). 유리구슬 안에서 색이 흐르고, 말소리에 표면이 출렁이며 물결이 퍼져요. 생각 중에는 산호색 호가 돌아요.
- 글씨는 본문 18px 안팎, 버튼 높이는 48px 이상이에요.

## 지도
- 일정(`schedule.json`)의 날짜와 순서를 그대로 쓰고, 관광지 안내는 `spots.json`에 따로 있어요. `spots.json`은 일정 항목 id → 장소 연결표예요. 폰에서 그 항목의 장소를 바꾸면 "확인 필요"로 바뀌어요.
- 관광지 설명은 공식 홈페이지, 시·주정부, Parks Canada 자료를 확인해서 쓰고 출처·확인일을 함께 적어요. 좌표는 Wikidata에서 가져와요(Google 좌표는 쓰지 않아요). 확인이 안 된 곳은 설명과 핀 없이 이름만 나와요.
- **키가 없어도**: 날짜별 장소 카드, 설명, 주소 보여주기(운전기사용 흰 화면), 길찾기(Google 지도 앱으로 연결, 차/대중교통/걸어서 중 선택), Google 지도에서 근처 식당 찾기를 쓸 수 있어요.
- **Google 지도 키를 넣으면** (설정 → Google 지도 키, Map ID는 선택): 번호 핀이 있는 지도와 카드 넘기기(◀ ▶ 버튼도 있음), ＋/－ 확대 버튼, 내 위치, 전체 일정 보기(날짜별 색), 근처 음식점(관광지 기준 가까운 순 5곳, 반경 800m → 1.5km → 3km)이 나와요.
- 음식점은 Google Places(New)의 Nearby Search로 찾아요. 이름·평점·영업시간 같은 Google 정보는 저장하지 않고, 읽어 주지도 않아요(Google 약관). "자료: Google Maps"를 함께 보여 줘요. 거리는 직선거리예요.
- 키는 브라우저용 키라서 Google Cloud에서 웹사이트(`https://ageg1126-web.github.io/*`)와 API(Maps JavaScript API, Places API (New))를 꼭 제한해 두세요. 예산 알림은 알림일 뿐 자동으로 막아 주지 않아요.
- 개인정보·이용 안내: `privacy.html` (설정 화면 맨 아래 링크)

## 사진 번역
- 탭을 열면 뒤쪽 카메라가 켜져요. 메뉴판·표지판을 맞추고 셔터를 누르면 사진을 OpenAI(`gpt-6.1-sol`, 추론 medium)로 보내 한국어 번역과 짧은 설명을 보여 줘요. "앨범에서 고르기"로 찍어 둔 사진도 번역할 수 있어요.
- 메뉴판은 음식마다 가격과 어떤 음식인지 설명이 붙고, 안내문은 무엇을 해야 하는지 알려 줘요.
- 사진은 긴 변 1600px JPEG로 줄여 보내요. 한 장에 1센트 미만이에요. 다른 탭으로 가면 카메라가 꺼져요.

## 여행 도구
- **환율 계산**: 캐나다 달러 ↔ 원. 무료 환율(open.er-api.com → frankfurter.app → jsDelivr currency-api 순)을 불러와 폰에 저장해 두고, 인터넷이 없으면 마지막 환율로 계산해요. 환율을 직접 넣을 수도 있어요.

## 일정
- 링켄리브 견적서(캐나다 로키 기차여행 6박 8일, 2027-07-18 ~ 07-25)를 날짜별로 `schedule.json`에 옮겨 두었어요.
- 캐나다 시간과 한국 시간을 함께 보여 주고, 날짜에 맞춰 밴쿠버(태평양) → 재스퍼부터 산악 시간대로 자동으로 바꿔요. 출발 전엔 D-day, 여행 중엔 몇 일째인지 나와요.
- 여행 중에는 오늘 날짜로 바로 이동하고 "오늘" 표시가 붙어요. 장소를 누르면 구글 지도가 열려요.
- ＋ 버튼으로 추가, 일정을 눌러 수정·삭제할 수 있어요. 휴대폰에서 고친 내용은 그 폰에만 저장돼요.
- `schedule.json`을 고쳐서 올리면(버전 숫자 올림) 모든 폰에 새 일정이 들어가요. 폰에서 직접 고친 게 있으면 "새 일정 불러오기" 안내가 떠요.
- 공유 버튼으로 전체 일정을 글로 보내거나 복사할 수 있어요.

## 통역 사용법 (엄격한 규칙)
**통역 모드**: 첫 화면은 가운데 원과 하단 "통역 시작" 버튼뿐이에요. 누르면 전체화면이 되고, 평소엔 완벽한 원이다가 말소리가 나면 테두리가 불규칙하게 크게 출렁여요. 하단 마이크 버튼으로 잠시 끌 수 있어요.
- AI는 대답하지 않고 **그대로 통역만** 해요. 한국어 → 영어, 영어 → 한국어, 순서 상관없이.
- 현지인이 실제로 말하는 자연스러운 표현으로 옮기되, 내용을 더하거나 빼거나 해석하지 않아요. 이름·숫자·가격·시간은 그대로.
- 번역 결과가 목표 언어가 아니면(예: AI가 대답해 버린 경우) 버리고 무료 번역으로 다시 해요.
- 휴대폰이 읽는 동안에는 듣기를 잠깐 멈춰서 자기 목소리를 다시 통역하지 않아요.

**통역 중단(✕) → 첫 화면 + AI 비서**: ✕를 누르면 통역이 멈추고 첫 화면(가운데 원, 하단 마이크 버튼과 "통역 시작")으로 돌아와요. 이때 마이크가 켜진 채로 AI 비서가 들어요.
- **한국어만** 알아듣고(영어는 무시), **한국어로만** 대답해요. 엄마가 묻는 말에 AI가 답하는 기능이에요.
- 여행 일정, 현재 시각(밴쿠버·캘거리·한국), 캐나다 달러 환율을 알고 있어서 "오늘 일정 뭐야?", "환율 얼마야?" 같은 질문에 바로 답해요. 일반 상식 질문도 답하고, 실시간으로 알 수 없는 것만 확실하지 않다고 해요.
- 질문과 답은 원 아래에 짧게 보여요. "통역 시작" 옆 마이크 버튼으로 AI 비서 마이크를 끄고 켤 수 있어요.
- 오른쪽 위 **원문 보기**에서만 지금까지의 통역과 AI 대화를 볼 수 있어요. 원문 보기 중에는 마이크가 완전히 꺼지고, 하단 "통역 시작"으로 바로 통역에 들어갈 수 있어요.
- AI 비서는 OpenAI 키가 있어야 동작해요.

**목소리**: 키가 있으면 OpenAI 음성(`gpt-4o-mini-tts`, 기본 목소리 marin)으로 읽어 줘요. 설정에서 목소리를 바꾸거나 폰 기본 음성으로 돌릴 수 있고, OpenAI 음성이 실패하면 자동으로 폰 음성으로 읽어요.

**실시간 동시통역 (기본)**: 키가 있으면 OpenAI의 통역 전용 모델 `gpt-realtime-translate`를 써요. 말하는 도중에 바로 통역 음성이 나와요. 대답하는 기능이 없는 모델이라 통역만 해요.
- 한 마이크로 두 세션을 열어요. 하나는 한국어를 영어로, 하나는 영어를 한국어로 통역해요. 세션은 자기 언어로 들어온 말을 그대로 따라 말하기 때문에, 각 세션이 받아 적은 말의 언어를 보고 따라 말하는 쪽의 소리와 자막은 꺼요(언어를 알기 전까지도 꺼 둬요).
- 휴대폰이 영어로 말하는 동안에는 영어→한국어 세션에 마이크를 잠깐 막아서(반대도 마찬가지) 자기 목소리를 다시 통역하지 않아요.
- 비용은 세션당 1분에 0.034달러, 두 세션이라 통역 화면을 켜 둔 동안 1분에 약 0.07달러(약 100원)예요. 2분 동안 아무 말이 없으면 저절로 꺼져요.
- 이 모델은 지시문을 받지 않아서, 공손한 영어로 옮기라는 규칙은 문장 단위 방식에서만 적용돼요. 목소리는 말하는 사람 목소리를 닮게 나와요.
- 연결이 안 되면 자동으로 문장 단위 방식으로 통역해요. 설정 → 통역 방식에서 바꿀 수 있어요.

## 두 가지 모드
| 모드 | 조건 | 동작 |
|---|---|---|
| 자동 감지 | 설정에 OpenAI API 키 입력 | 마이크를 계속 열어 두고 말이 끝날 때마다(기본 0.8초 쉼) 잘라서 OpenAI 음성인식(`gpt-4o-mini-transcribe`, 안 되면 `whisper-1`)에 보내요. 결과 글자가 한글이면 한국어, 알파벳이면 영어로 판단해요. 번역·AI 비서·사진 번역은 `gpt-6.1-sol`(추론 medium)로 하고, 계정에서 그 모델을 못 쓰면 `gpt-4o-mini`로, 그것도 실패하면 무료 번역으로 넘어가요. |
| 기본 모드 | 키 없음 | 브라우저 무료 음성인식. 한 번에 한 언어만 들을 수 있어서 한국어와 영어를 번갈아 들어요. |

### 비용과 키
- OpenAI 음성인식은 1분에 약 0.3센트(gpt-4o-mini-transcribe 기준)라 여행 내내 써도 몇 달러 수준이에요. 번역 비용은 그보다 훨씬 적어요.
- 키는 그 휴대폰 브라우저에만 저장돼요. OpenAI 대시보드에서 **월 지출 한도**를 꼭 걸어 두세요.
- 키 칸은 비밀번호 칸이 아니라서 브라우저가 자동으로 채우지 않아요(예전에 Chrome이 저장해 둔 다른 키를 채워 "키가 맞지 않아요"가 났어요). OpenAI 칸에 `AIza…`(Google 키)를, 지도 칸에 `sk-…`(OpenAI 키)를 넣으면 저장하지 않고 알려 줘요.
- 키는 채팅이나 저장소에 절대 올리지 마세요.

### 알아두실 점
- 음성인식과 번역 모두 인터넷이 필요해요. 캐나다 데이터 로밍/eSIM을 준비하세요.
- 아이폰은 마이크가 켜져 있을 때 읽어주는 소리가 작게 날 수 있어요. 실제 폰으로 꼭 시험해 보세요.
- 주변이 시끄러우면 말 끝을 늦게 알아챌 수 있어요. 설정의 "말 끝 감지"로 조절할 수 있어요.

## 파일
- `index.html`, `style.css` — 화면과 탭
- `app.js` — 탭, 설정, 통역 흐름(자동 감지 / 기본 모드)
- `audio.js` — 마이크를 계속 듣다가 말 한 마디씩 잘라 주는 부분
- `stt.js` — OpenAI 음성인식
- `orb.js` — 소리에 맞춰 움직이는 원 애니메이션
- `realtime.js` — 실시간 동시통역 (gpt-realtime-translate, WebRTC 두 세션)
- `ai.js` — 모든 기능이 쓰는 AI 모델 설정(gpt-6.1-sol, medium)
- `cards.js` — 보여 주는 카드 (호텔로 데려다 주세요, 영어 못해요, 길 잃음, 가이드 전화, 알레르기·약, 911 등 큰 글씨 영어 화면. 내 정보와 직접 만든 카드는 이 폰에만 저장)
- `weather.js` — 여행지별 날씨(Open-Meteo)와 옷차림 팁, 7월 평균 기온
- `packing.js` — 짐 체크리스트 (출국 전, 옷, 기차 1박, 호텔 나올 때, 귀국 전)
- `tools.js` — 여행 도구 화면의 도구 전환
- `tips.js` — 팁·세금 계산 (밴쿠버 BC주 / 로키·캘거리 앨버타주, 식당·쇼핑)
- `assistant.js` — 통역 중단 후 한국어 AI 비서
- `schedule.js`, `schedule.json` — 일정 화면과 여행 일정 데이터
- `camera.js` — 사진 번역
- `currency.js` — 환율 계산
- `translate.js` — 번역 (OpenAI → 무료 Google → MyMemory 순)
- `manifest.json`, `sw.js`, `icon*` — 홈 화면 앱(PWA) 설정
